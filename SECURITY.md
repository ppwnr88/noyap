# Security Policy

## Supported Versions

Noyap is pre-1.0. Security fixes target the latest published version.

## Reporting a Vulnerability

Please report vulnerabilities through GitHub Security Advisories:

https://github.com/ppwnr88/noyap/security/advisories

Do not open a public issue for secrets, token exposure, or exploitable behavior.

## Scope

Relevant reports include:

- unsafe file overwrite behavior
- command injection risk
- package publishing or installation risk
- generated rules that remove security, data-loss, or secret-exposure warnings
- dependency vulnerabilities with a realistic exploit path
