# Code of Conduct

Noyap follows the [Contributor Covenant](https://www.contributor-covenant.org/) spirit: be respectful, constructive, and welcoming.

## Expected Behavior

- Be kind and direct.
- Assume good intent.
- Give actionable feedback.
- Respect different language backgrounds and developer communication styles.

## Unacceptable Behavior

- Harassment, insults, or personal attacks
- Discriminatory language
- Dismissive comments about Thai, English, or mixed-language usage
- Publishing private information without permission

## Reporting

Open a private security report for security issues. For conduct concerns, contact the maintainers through GitHub.
